# Original CTS Amber assets

These seven unchanged files are from Vulkan-CTS revision
`5a9cb32498158eb60774cf8a3d4e0b8c68f7fe9e`. Their source-defined relative
paths are preserved. Copy `vulkan/` into the probe directory used by the Amber
runner; every file is hash-pinned and staged beneath its exact archive root.
The original CTS executable, shader bodies, inputs and EXPECT checks are
unchanged. Apache2.0 license and upstream notice are retained in
`../scratch-provenance/`. This is original CTS coverage, unlike the separate
core ScratchSpace adapter.
